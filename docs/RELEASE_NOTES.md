## Highlights

- One real-time wallet experience across Next.js, PWA, and Expo.
- Personal and organization accounts with role-aware access.
- Handle, request, QR, scheduled, budgeted, and split-bill payment workflows.
- Simulated Bangladesh MFS, bank, and card rails.
- Notification inboxes, Web Push, and Android push through Expo/FCM.
- Better Auth email/password, email verification, and password recovery through Brevo SMTP.
- Receipts, history, analytics, and exportable PDF statements.
- Light/dark themes, bottom-tab navigation, reduced-motion support, and branded install assets.

## Release validation

- Web lint, TypeScript, unit tests, and production build.
- Native TypeScript, 62 unit tests, Expo Doctor, dependency compatibility, and signed release build.
- Convex development and production deployments.
- Android package metadata, signature, archive integrity, and emulator smoke flow.
- Production landing, authentication endpoint, payment-link redirect, and security headers.

The APK is built locally with EAS CLI and the configured Android release keystore. No GitHub Actions workflow is used.
